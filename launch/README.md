# Diagram Grill launch kit

This directory contains internal, English-only launch material. Nothing here
authorizes making the repository public, posting to a community, opening an
external pull request, or contacting anyone. Each external action requires
separate approval.

## Non-negotiable rules

- Target English-speaking developers and the Agent Skills ecosystem. Do not
  use Korean launch channels.
- Never invent evaluation results, users, installs, stars, testimonials, or
  client compatibility.
- Name a client only after an end-to-end test records its client version,
  model, runtime, prompt, transcript, and artifacts.
- A fixture count describes the evaluation protocol, not product performance.
- Do not publish aggregate prelaunch results until all 24 planned runs have
  been retained and reviewed.
- The demo must use an actual retained baseline failure. Do not stage a bad
  baseline output or reconstruct a conversation for the recording.
- The user writes the final Show HN and Reddit prose. Their files in this
  directory are facts and outlines, not submission-ready copy.
- Keep hidden telemetry out of the project. Use public repository traffic,
  installer data exposed by the distribution channel, and opt-in feedback.

## Files

- [`channel-calendar.md`](channel-calendar.md): gated release sequence and
  channel checklists.
- [`x-draft.md`](x-draft.md): short X draft with evidence placeholders.
- [`show-hn-outline.md`](show-hn-outline.md): facts and structure for the
  user-authored Show HN submission.
- [`reddit-outline.md`](reddit-outline.md): experience-report structure for
  the user-authored Reddit post.
- [`article-outline.md`](article-outline.md): Dev.to and Hashnode article
  outline.
- [`github-topics.md`](github-topics.md): base and compatibility-gated topics.
- [`demo-storyboard.md`](demo-storyboard.md): evidence-gated 20–30 second demo.
- [`claims-checklist.md`](claims-checklist.md): minimum evidence for every
  public claim.

## Stop condition

If a required evidence link is blank, the related claim or channel action is
not ready. Remove the claim or postpone the action; do not soften an unsupported
claim with words such as “likely,” “should,” or “generally.”
